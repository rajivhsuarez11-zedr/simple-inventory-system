# Inventory Manager

A simple inventory web app for tracking products, stock levels, and inventory value.

## Features

- Add new products
- Update stock quantities
- Delete product records
- Search inventory by name, SKU, or category
- Highlight low-stock items
- View summary stats
- Persist data in localStorage

## Run locally

1. Open `index.html` in a browser, or
2. Serve the folder with a simple local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Files

- `index.html` – app structure
- `styles.css` – styling
- `app.js` – logic and state management
